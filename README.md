# Linear_DataStructure

## 프로젝트 소개
선형 자료구조를 공부하며 간단한 DBMS를 구현하는 프로젝트

연결 리스 기반 선형 자료구조에 대한 이해와 DBMS 시스템과 자료구조의 관계에
관한 코드 수준의 깊은 이해
(select문을 지원하는 주소록 개발)

## 구현 목록
- [ ] 배열 (Array)
- [ ] 연결리스트 (Linked List)
- [ ] 스택 (Stack)
- [ ] 큐 (Queue)
- [ ] 이벤트 루프(Event loop)
- [ ] DBMS 구현

## 개발 환경
